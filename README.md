## 📊 Education Dropout Analysis & Early Warning System

A **Python-based Data Science application** that analyzes educational datasets to identify dropout trends and detect early warning signals for NGOs and educational institutions.

### Key Features

- Dataset upload and validation  
- Dropout trend analysis  
- Exploratory Data Analysis (EDA)  
- Interactive visualizations  
- Early warning detection system  
- Optional machine learning prediction  
- Interactive dashboard built with Streamlit  

### Tech Stack

Python • Pandas • NumPy • Scikit-learn • Matplotlib • Seaborn • Streamlit
